# 🌈 牛津自然拼读 · 26个字母练习

单文件网页小程序，适合 3-8 岁小朋友学习 26 个英文字母。

## 功能
- 📖 **学习**：26 个字母，每个含大小写、发音音标、4 个单词（emoji + 中文释义）
- ✍️ **书写**：描红练习，大写 + 小写笔画顺序提示
- 🎯 **练习**：听音选字母 / 看图选首字母 / 听词选首字母 / 听词选图，含错题复习
- 🃏 **配对**：大小写字母记忆配对游戏
- ⭐ 掌握度追踪 + 星星奖励，进度保存在本地浏览器

## 使用
直接打开 https://hu838826790.github.io/oxford-phonics/ 即可，无需安装、无需联网接口，发音用浏览器自带语音，完全免费。
